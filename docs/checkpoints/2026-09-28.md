# September 28, 2026 checkpoint

The first connected workflow is implemented in the maintained app:

**Watch Me → saved source → manual collection → archived results → continuing cards
→ focused discussion → accepted task → shared executor.**

## Delivered

- Watch Me collects a description and optional context before generating a draft.
  Large drafts open in a separate native text window. Sources can be edited,
  removed and restored.
- Source definitions and run results have separate repositories and views. Each
  run has a readable timestamp folder, authoritative JSON and readable exports.
- A shared task executor handles execution; ingestion and card generation produce
  task plans, domain services validate and save outcomes, and views load saved state.
- SQLite stores continuing cards, human decisions/context, accepted work and
  generation receipts. Source/item keys support deduplication and newer evidence
  updates; absence alone never resolves a card.
- Card discussion can adjust context, mark a matter handled or reopened, and queue
  an action when requested. Accepted tasks retain their own instruction snapshots.
- The reproduced chat layout freeze was fixed by replacing the transcript's lazy
  stack. Bounded automatic stall diagnostics and replay checks remain available.
- The signed local app was rebuilt and installed with its existing Dock icon,
  reopen behavior, normal Quit and visibility in macOS Force Quit.

## Verification

The final checkpoint suite passed **427 tests across 62 suites** in an isolated
data directory. The release build, bundle configuration and installed app identity
were checked. Live checks covered generation from saved results, duplicate
generation, card discussion and the previously freezing follow-up. Private user
data, process samples and rendered reply fixtures are not part of this checkpoint.

## Remaining boundaries

- Collection is manually triggered; daily scheduling is not implemented.
- Item identity is best effort and scoped to a source. Native client controls
  constrain collection and tracked-thread rechecks; broad client compatibility
  has not been established. Unverifiable tracked items stay unresolved.
- Card generation uses supplied context; relationship inference and learned
  personalization remain future work.
- The exact infinite layout loop passed its live replay after the fix. Later
  diagnostics recorded recovering pauses that still need triage; this checkpoint
  does not claim that all UI stalls are eliminated.
- Persistence has a replaceable repository boundary, but database operations are
  still synchronous on the main actor. Larger datasets may warrant moving them.
