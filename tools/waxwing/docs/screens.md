# Waxwing screens: what the URL means and what is on it

Everything is one page at `/` with query parameters. Persistent chrome on every screen:
- **Header**: brand "waxwing / Library" on the left; on the right a workspace-name badge and a button showing the signed-in user's name (opens **Account and access**).
- **Left sidebar** = the library: "WORKSPACE" with an entry count; **New page** (primary button); **＋ New drawing**; **Import explanation** (file picker for a canonical model JSON ≤ 1.9 MB, shows "Preparing explanation…"); nav buttons **Work reports**, **Needs attention**, **Telemetry**, **Connected repositories** (owners only), **Workspace home**; a "PAGES" collapsible tree (collections → pages → subpages, per-collection counts, "No pages yet"); at the bottom **Use from an agent or terminal** (opens /api/guide) and **Open sample explanation**.
- **Main area top**: a dismissible red error banner with **Refresh library** when something failed; **Breadcrumb** (Workspace / Collection / Title / Record); **Collection navigation** with **Home** and **Contents** tabs (Home only exists when the collection has a home); the **Search your workspace** bar (scope dropdown + query + **Search** / **Close search**), present everywhere except Work reports and Account and access.

| URL | Screen | What is on it |
|---|---|---|
| `/` | **Workspace home** | Eyebrow "YOUR WORKSPACE", heading "A map of what we know.", **New collection** button; a stat row (collections / explanations / in your inbox); one card per collection ("… explanations", **Explore →**); an inbox banner ("N explanations are ready to organize", **Open inbox →**); an "All pages" list. |
| `/?collection=ID` | **Collection** | Shows the collection's **home** page or model if one is set, otherwise its contents. Eyebrow "COLLECTION / READING ORDER", title and description, **Edit collection** (name, Description, and a **Collection home** select that includes "Contents — no home page"). |
| `/?collection=ID&view=contents` | **Contents** (table of contents) | A numbered tree. Each entry: title link, a kind caption ("Written page", "Standalone drawing", "Data model · ERD", or the model's guiding question), record and revision counts, **Collection** and **Parent page** selects, ▲ ▼ reorder buttons. |
| `/?collection=inbox` | **Inbox** | "READY TO ORGANIZE" / "Unfiled pages": entries with no collection yet. |
| `/?page=ID` | **Page reader** (current version) | Page-hierarchy breadcrumbs; **New subpage**, **Edit page**; author line; **Collection** / **Parent page** / **Saved versions** selects; a "Changed since written" banner with **Confirm current** when citations drifted; the prose; panels **Cites**, **Cited by**, **Subpages**, **Linked pages**. |
| `/?page=ID&version=V` | **Saved page version** (read-only) | Eyebrow "PAGE / SAVED VERSION"; link **Read current version**. |
| `/?page=new` (optionally `&collection=…&parent=…`) or editing | **Page editor** | "Write a new page" / "Edit page"; **Page title** field; writer with **Write / Markdown / Preview** tabs and a toolbar (Normal text, Heading 1–3, Bold, Italic, lists, Checklist, Insert table, Insert or edit link, Undo/Redo); word and character count footer; **Linked pages** fieldset (Choose a page…, **Add link**, "Follow current page" or a saved version, **Remove**); **Save page** / **Cancel**; draft status "Draft kept in this tab · Not saved to workspace". ⌘S saves. |
| `/?page=new-drawing` or a drawing item | **Drawing** | "Draw a new idea" / **Edit drawing**; **Drawing title**; the Excalidraw canvas; **Save drawing** / **Cancel**. Read mode shows "Drawing contents · N objects", **Saved versions**, **Read current drawing**. |
| `/?revision=R` (plus `&record=…`, `&document=…`, `&note=…`) | **Explanation reader** | Eyebrow "EXPLANATION / SAVED REVISION" or "DATA MODEL / SAVED REVISION"; **Full screen diagram**; the revision digest; **Saved revisions** select; **What changed?** panel; a record toolbar ("Find a record" + record select); optional "Related architecture" links; the diagram in a sandboxed frame (inside it: zoom, **Fit**, **Model inspector**, **Close details**); a right panel **Contributions** (notes) for the selected record with **Cited by pages**, **Copy link to this record**, **Save note**. |
| `/?revision=R&diagram=1` | **Full screen diagram** | The diagram alone. |
| `/?item=ID` (optionally `&record=…`) | **Citation resolver** | Not a screen: the app looks the item up in the library and rewrites the URL to `?page=` or `?revision=`. Error "The cited item is not in this workspace." if it is gone. |
| `/?snapshot=ID&version=V` | **Saved collection introduction / dashboard configuration** | Read-only saved title and body. |
| `/?collection=work-reports` and `&report=ID` | **Work reports** list / reader | Filter box; "Instructions for your agent"; a report has sections: Scope of this attempt, Findings and their basis, Procedure for reuse, Checks, Unresolved questions, Evidence snapshots; **Review this submission** (Question / Challenge / Acknowledgement, **Save review**). No search bar here. |
| `/?collection=attention` | **Needs attention** | "What may no longer be true." and the list of pages whose citations drifted; **Refresh**. |
| `/?collection=telemetry` | **Telemetry** | "Your systems, in view."; **Add embed**, filters, per-app groups of embedded dashboards, **Edit** / remove, **Refresh embeds**. |
| `/?collection=repositories` | **Connected repositories** (owners only) | **Connect a source**: Explanation type (Architecture explanation / Relational data model), Name, Repository URL, Branch, Question to explain, Schema snapshot path, **Explanation to refresh**, **Save connection**; per connection **Update explanation** / **Refresh schema** with run status. |
| `/?collection=access` | **Account and access** | **Sign out**; Invite a member (**Create invitation**); Pending invitations; Members; Your agent tokens (**Create agent token**, Read / Read and write); Change your password. No search bar here. |
| `/?q=…` (plus `history`, `searchCollection`) | **Search results** overlay | "Results for “…”", an **Include older revisions** checkbox, hits with source/kind badges and "Exact match"; **Close search** returns. |
| `/#setup=…`, `/#invite=…`, `/#recover=…`, or signed out | **Auth screens** | "Sign in to Waxwing", "Set up the workspace owner", "Accept your invitation", "Choose a new password". |
| `/api/guide`, `/api/…` | **Agent guide / API** | HTML instructions for agents and terminals; JSON operations. Not workspace content. |
